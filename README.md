# Алгоритмы по шагам

Статический сайт-тренажёр. Сортировки, поиск, индексация, хеширование, кодирование, деревья и базовые структуры данных разобраны по шагам: схема, пояснение к каждому действию и код с подсветкой текущей строки. Тесты по темам с четырьмя вариантами ответа. Все вычисления выполняются в браузере. На github.io ведется анонимная статистика

## Запуск

Откройте `index.html` в браузере.

Или откройте сайт: [![Открыть](https://img.shields.io/badge/Открыть-green?style=for-the-badge)](https://pirat3571.github.io/graphical-algorithms/)

## Разделы

| Файл | Что показывает |
|---|---|
| `index.html` | Главная страница со списком разделов |
| `sort.html` | Девять сортировок, счётчики сравнений C и перемещений M, мини-тест по выбранной сортировке |
| `binary-search.html` | Бинарный поиск символа: тип 1 (точное вхождение) и тип 2 (позиция вставки) |
| `indexing.html` | Индексный массив символов, направление сортировки и фильтры «гласные / согласные» |
| `hashing.html` | Хеш-таблица настраиваемого размера: цепочки, линейные и квадратичные пробы |
| `coding.html` | Коды Шеннона, Фано, Хаффмана и Гилберта—Мура: вероятности по частотам, неравенство Крафта, средняя длина и энтропия |
| `structures.html` | Массив, список, стек и очередь: пробуйте операции и смотрите, как меняется память. |
| `test.html` | Общий тест на 33 вопроса, у каждого четыре варианта ответа и пояснение |
| `trees.html` | Страница выбора для раздела «Деревья» |

## Деревья

| Файл | Что показывает |
|---|---|
| `isdp.html` | ИСДП: идеально сбалансированное дерево поиска |
| `sdp.html` | СДП: случайное дерево поиска |
| `sdp-delete.html` | Удаление из СДП |
| `avl.html` | Построение АВЛ-дерева, повороты |
| `avl-delete.html` | Удаление из АВЛ-дерева с балансировкой |
| `btree-m.html` | Б-дерево порядка m, расщепление |
| `btree.html` | Двоичное Б-дерево поиска (ДБД), флаги VR и HR |
| `optimal-exact.html` | Оптимальное дерево поиска, точный алгоритм (матрицы W, P, r) |
| `optimal-approx.html` | Оптимальное дерево поиска, приближённые алгоритмы |

## Общие файлы

В папке `assets/`:

- `style.css`: оформление, три темы (светлая, тёмная, AMOLED), адаптивная вёрстка, кастомные поля ввода и кнопки.
- `core.js`: разбор ввода, раскладка и рисование деревьев, пошаговый плеер, переключение темы, фоновые частицы, кнопки «−» и «+» для числовых полей.
- `algo.js`: столбики сортировок, карманы цифровой сортировки, полоски символов, индексные массивы.
- `pocket.js`: выезжающая вкладка с кодом, в которой подсвечиваются строки текущего шага.
- `quiz.js`: движок мини-тестов и все вопросы.
- `favicon.ico`: иконка сайта.

## Управление

- Плеер: кнопки «Назад» и «Дальше», ползунок шага, «Авто». С клавиатуры работают стрелки ← и →.
- Код: вкладка «{ } посмотреть код» справа. Esc закрывает её. Открыта она или нет, браузер запоминает отдельно для каждой страницы.
- Тема: кнопка в правом верхнем углу переключает светлую, тёмную и AMOLED(черную).
