Удаление из случайного дерева поиска

Сначала дерево строится по первому набору букв, затем из него по очереди удаляются ключи из второго поля. Для каждого удаления показываются поиск узла и один из трёх случаев: лист, один потомок, два потомка.

Пробелы и запятые между буквами можно ставить для удобства. Если ключа нет, дерево не меняется.

Три случая удаления

1. ЛистУ удаляемого узла нет потомков — просто отрезаем его от родителя.
2. Один потомокПодставляем единственного потомка на место удалённого узла.
3. Два потомкаНаходим максимум в левом поддереве (предшественника), переносим его ключ в удаляемый узел и удаляем предшественника — у него уже нет правого потомка. Можно взять и минимум правого поддерева (преемника): тогда у него нет левого потомка.
