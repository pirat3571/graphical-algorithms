Оптимальное дерево поиска: точный алгоритм

Вершины V1…Vn упорядочены по ключам (это могут быть любые символы или числа), у каждой есть вес Wj — частота обращения. Нужно построить двоичное дерево поиска с минимальной взвешенной высотой. Матрицы Wij, Pij и rij заполняются по рекуррентным формулам, а структуру дерева полностью задаёт матрица корней rij.

Ключи можно писать подряд (ABC) или через пробел и запятую (10 20 30); вес вводится в том же порядке. Вершины автоматически упорядочиваются по ключам.

Матрицы Wij, Pij, rij

Wij — вес поддерева Tij, Pij — его взвешенная высота, rij — номер корня. Подсвечена вычисляемая ячейка, зелёным — ячейки, из которых она считается.
Формулы и идея алгоритма

Для любого дерева поиска справедливо соотношение P = PL + W + PR, где PL и PR — взвешенные высоты левого и правого поддеревьев, а W — вес всего дерева: оба поддерева опускаются на уровень ниже и добавляют свой вес ещё раз.

Через Tij обозначено оптимальное поддерево из вершин Vi+1…Vj, через Wij и Pij — его вес и взвешенная высота. Поддерево Tii пустое: Wii = 0, Pii = 0. Для 0 ≤ i < j ≤ n:

(1) Wij = Wi,j−1 + Wj

(2) Pij = Wij + mini<k≤j (Pi,k−1 + Pk,j)

Значение k*, при котором достигается минимум, записывается в матрицу rij: это номер корня поддерева Tij в упорядоченном массиве вершин. При равенстве берётся наименьшее k.

Построение дерева по матрице r. Корень всего дерева — вершина с номером k = r0,n. Её левое поддерево описывает r0,k−1, правое — rk,n, и так далее для каждого отрезка (i, j), пока i < j. Если i = j, поддерево пустое. Сложность вычисления матриц — O(n³).
