Оптимальное дерево поиска: приближённые алгоритмы

Точный алгоритм требует O(n³). Быстрые алгоритмы A1 и A2 строят почти оптимальное дерево: A1 берёт в корень вершину с наибольшим весом, A2 выбирает «центр тяжести» отрезка вершин. Ниже оба алгоритма сравниваются с точным оптимумом по средней взвешенной высоте h = P / W.

Ключи можно писать подряд (ABC) или через пробел и запятую (10 20 30); вес вводится в том же порядке. До 12 вершин. Для A2 вершины автоматически упорядочиваются по ключам.

Сравнение с точным оптимумом

P = Σ Wj · (глубинаj + 1) — взвешенная высота дерева, h = P / W — средняя взвешенная высота (среднее число сравнений при поиске).
Как работают алгоритмы A1 и A2

Алгоритм A1. Вершины сортируются по убыванию весов, затем по очереди добавляются в дерево поиска обычным способом (Добавить(Root, Vi)). Самые тяжёлые вершины оказываются у корня. Ключи при этом не обязаны быть упорядочены заранее, зато форма дерева может сильно отличаться от оптимальной. Вершины с равными весами добавляются в порядке возрастания ключей.

Алгоритм A2. Вершины упорядочены по возрастанию ключей. Для отрезка VL…VR с общим весом W ищется «центр тяжести» — вершина Vk, для которой

Σi=Lk−1 wi < W/2 ≤ Σi=Lk wi

Она становится корнем, после чего то же делается для левого отрезка VL…Vk−1 и правого Vk+1…VR. Для большей точности дополнительно рассматриваются соседние вершины Vk−1 и Vk+1: корнем берётся та из трёх, у которой суммарные веса левой и правой частей отличаются меньше всего. Флажок «Уточнение» включает и выключает этот шаг.

Оба алгоритма работают быстро (A2 — за O(n log n) и меньше), но оптимум не гарантируют: точный результат даёт только динамическое программирование из предыдущей страницы.
